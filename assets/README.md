# Assets лендинга ComLead

Материалы извлечены из последнего созданного index.html (ComLead / comlead.pro).

- `sergey-solodyankin.jpg` — исходный портрет, используемый в первом экране. Кадрирование задается в CSS.
- `comlead-logo.svg` — векторный логотип; также используется как favicon.
- `comlead-logo.png` — растровая версия логотипа с прозрачностью вне круга.
- `Inter-Regular.ttf`, `Inter-Bold.ttf` — шрифт основного текста.
- `PlayfairDisplay-Regular.ttf` — шрифт заголовков.
- `styles.css` — оформление и мобильная адаптация.
- `main.js` — переключение задач, калькулятор окупаемости, мобильное меню.

В архиве ComLead_landing.zip находится index.html с относительными ссылками на эту папку assets. Сохраните структуру папок при переносе на хостинг. Все изображения и шрифты локальные.

Оригинальный HTML в основной папке ComLead остается автономным: его изображения, шрифты, стили и скрипты встроены в файл.
